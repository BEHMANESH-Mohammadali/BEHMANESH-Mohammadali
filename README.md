Behmanesh Structural Index (BSI)

BSI — Behmanesh Structural Index / شاخص ساختاری بهمنش is a layered, interdisciplinary framework for structural analysis of intellectual content. It is designed to extract and examine patterns, themes, intellectual development, worldview, and underlying mechanisms rather than treating textual volume as analytical quality.

The current implementation and benchmark work focus on reproducible evaluation of structured analysis, including comparisons between default/raw analysis and BSI-guided analysis.
